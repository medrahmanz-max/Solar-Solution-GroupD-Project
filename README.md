
Solar Solution
Solar Solution is a collaborative web application designed to provide clean energy solutions and insights. This project was developed as a group initiative using React powered by Vite for a fast, modern web experience.

🛠️ Tech Stack
Frontend Framework: React

Build Tool: Vite

Styling & Components: Modular component architecture per page

🚀 Key Features & Project Structure
Page-Based Architecture: Each section of the website was independently designed and integrated by designated team members.

Modern Tooling: Optimized build times and fast Hot Module Replacement (HMR) powered by Vite.

## Pages
- `/` Home — hero, service overview icons, testimonials
- `/services` Services — 4 alternating image/text rows (Residential, Commercial, Storage, Maintenance)
- `/gallery` Gallery — tabbed header, 12-image project grid, CTA band
- `/about` About Us — mission/sustainability/clean energy, team grid, values, history
- `/contact` Contact — contact form, contact info + map, FAQ accordion

## Setup

```bash
npm install
npm run dev
```
