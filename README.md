## Pages
- `/` Home — hero, service overview icons, testimonials
- `/services` Services — 4 alternating image/text rows (Residential, Commercial, Storage, Maintenance)
- `/gallery` Gallery — tabbed header, 12-image project grid, CTA band
- `/about` About Us — mission/sustainability/clean energy, team grid, values, history
- `/contact` Contact — contact form, contact info + map, FAQ accordion

## Supabase contact form

1. Copy `.env.example` to `.env` and replace the `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` placeholders with the values from your Supabase project settings.
2. In the Supabase SQL editor, create the submissions table and its insert-only policy:

```sql
create table public.contact_submissions (
	id bigint generated by default as identity primary key,
	name text not null,
	email text not null,
	phone text,
	message text not null,
	created_at timestamptz not null default now()
);

alter table public.contact_submissions enable row level security;

create policy "Allow anonymous contact submissions"
on public.contact_submissions
for insert
to anon
with check (true);
```

The form inserts into `contact_submissions`. No service-role key belongs in this frontend; review submissions from the Supabase dashboard or a protected admin backend.
